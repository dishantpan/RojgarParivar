# RojgarParivar — रोजगार परिवार

> A Hindi-language job portal connecting informal daily wage workers with employers.

![Status](https://img.shields.io/badge/Status-In%20Development-yellow)
![License](https://img.shields.io/badge/License-All%20Rights%20Reserved-red)

## 📌 About

RojgarParivar is a MERN stack web application designed to bridge the gap between 
daily wage workers (mazdoor) and local employers in India. The platform operates 
in Hindi to ensure accessibility for users with limited English proficiency.
